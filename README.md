# indexrest

Index HTML/Markdown rest fragments safely for docs pipelines.

**Site:** https://theworker02.github.io/indexrest/

## Install / run

```bash
git clone https://github.com/theworker02/indexrest.git
cd indexrest
node src/cli.js
node --test
```
